# studio-scripts

Reusable front-end scripts for Kevin Brenkman studio projects, served via jsDelivr.

- `core/` shared modules (MediaKit, ServiceHover, Swup helpers)
- `projects/<client>/` per-project bundles

Always load a tagged version: `https://cdn.jsdelivr.net/gh/kevinbrenkman/studio-scripts@vX.Y.Z/projects/paloma/paloma.js`
